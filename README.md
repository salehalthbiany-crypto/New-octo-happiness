# تطبيق بقالة العزي للمواد الغذائية - نظام نقاط البيع والمحاسبة الذكية
**Alozzi Grocery POS & Accounting Management System**

تطبيق متكامل لإدارة البقالات ونقاط البيع السريعة، حسابات العملاء والديون، إيصالات الدفع الحرارية ومشاركتها عبر واتساب، مع دعم كامل للعمل بدون إنترنت (PWA Offline) ودعم العملتين اليمنية (ر.ي) والسعودية (ر.س).

## 🚀 كيفية تشغيل المشروع محلياً (Quick Start)

### 1. المتطلبات:
* تثبيت **Node.js** (الإصدار 18 فما فوق).
* مدير الحزم `npm` أو `yarn` أو `bun`.

### 2. تثبيت الحزم (Dependencies):
```bash
npm install
```

### 3. تشغيل خادم التطوير (Development Server):
```bash
npm run dev
```
سيعمل التطبيق على الرابط: `http://localhost:3000` أو المنفذ الظاهر في المخرجات.

### 4. بناء المشروع للإنتاج (Production Build):
```bash
npm run build
```
سيتم إنشاء ملفات الويب الجاهزة داخل مجلد `dist/`.

## 📱 كيفية تحويل التطبيق إلى ملف أندرويد APK

1. **طريقة سريعة جداً (PWABuilder)**:
   - افتح الرابط: `https://www.pwabuilder.com/`
   - ضع رابط التطبيق المنشور واضغط **Package for Stores**.
   - اختر منصة **Android** ثم حمّل ملف الـ APK فوراً.

2. **طريقة أندرويد الرسمية (Capacitor)**:
   ```bash
   npm install @capacitor/core @capacitor/cli @capacitor/android
   npx cap init "بقالة العزي" "com.alozzi.pos"
   npm run build
   npx cap add android
   npx cap open android
   ```
   ثم من داخل **Android Studio** اضغط `Build -> Build APK`.
